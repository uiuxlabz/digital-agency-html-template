# DGcom — Digital Agency & Web Design Studio

A bespoke, framework-free HTML template for digital agencies and web design studios. Deep purple and neon pink on a dark surface — built to look like nothing else in the template universe.

## Design Distinction

**Color System:** Deep purple `#1A0A3E` meets violet `#7C3AED` and neon pink `#EC4899` on a near-black surface `#0F0A1A`. Every accent glows. Every gradient shifts.

**Typography:** Space Grotesk for bold display headlines, Inter for readable body copy, Fira Code for mono-spaced labels and technical accents. Three fonts, one voice.

**Hero:** Animated gradient background with a subtle grid overlay. Large headline — "We build *digital experiences*" — paired with floating project preview cards that rotate and drift with CSS keyframe animations.

**Project Grid:** 10-card masonry-style grid with hover lift, scale, and a 3D tilt effect powered by vanilla JavaScript mousemove tracking. Each card reveals project name and category on hover.

**Motion:** Card tilt on hover (CSS perspective transforms), gradient shift on hero (keyframe animation), stagger fade-in on project grid (IntersectionObserver with delay classes), infinite testimonial scroll track.

**Signature:** The animated gradient hero, the glowing project grid with tilt effects, and neon accents on a dark canvas make this template instantly recognizable.

## Features

- **Zero frameworks** — pure HTML, CSS, and vanilla JavaScript
- **Responsive** — mobile-first with burger menu, fluid grids, and clamp() typography
- **Accessible** — semantic HTML, aria labels, keyboard-navigable
- **Performant** — no build step, lazy-loaded images, passive scroll listeners
- **Animated** — scroll reveal, counter animation, card tilt, testimonial auto-scroll
- **Custom contact form** — client-side validation with success state

## Tech Stack

- HTML5 semantic markup
- CSS custom properties (design tokens)
- Vanilla JavaScript (IIFE pattern)
- Google Fonts (Space Grotesk, Inter, Fira Code)
- Lucide Icons (via CDN)
